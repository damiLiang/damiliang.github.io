Hugo 负责生成网页

GitHub 负责保存源文件

GitHub Actions 负责自动构建

GitHub Pages 负责发布网站

----------------------------------------------------------------------------------------------------------------------------

1、安装 Git 和 Hugo Extended。

2、使用 Hugo 创建博客项目。

3、使用 Git 管理博客文件。

4、安装 Ananke 等 Hugo 主题。

5、修改 `hugo.toml` 配置网站。

6、在 `content/posts` 中用 Markdown 写文章。

7、使用 `hugo server -D` 本地预览。

8、将博客项目推送到 GitHub。

9、GitHub Actions 自动运行 Hugo 构建。

10、GitHub Pages 发布生成的静态网站。
